# Engine

Python code for the board and legal moves lives here.

## Phase 1 goal

- Represent an 8×8 board and the candy pieces
- Generate and validate legal moves under standard chess rules
- Keep the code easy to read, with tests

Suggested start: `engine/board.py` and a small test file in this folder.

Setup notes (for example, a `requirements.txt` and how to run tests) should be added here once the engine exists.
