# Frontend

The interactive Candy Chess board lives here (JavaScript, HTML, and CSS).

## Phase 1 goal

- Draw an 8×8 board
- Show candy visuals for each piece
- Let a player click or drag to make a move
- Follow legal moves from the rules and engine (a simple placeholder is fine until the engine is ready)

Suggested start: `frontend/index.html`, plus CSS and JS files in this folder.
